# ペナント・レジェンズ開発ルール

- 既存の野球経営シミュレーションを引き継ぎ、ゲームを作り直さない。主な対象は `index.html`。基準ブランチは `main`。
- 不具合を指摘されたら説明だけで終わらせず、直ちに原因箇所のコードを修正する。
- 修正後は実際に対象の処理を動かし、再現手順と周辺機能で結果を確認する。保存を伴うテストには隔離したテストデータを使う。
- 既存のセーブデータを削除・初期化しない。保存形式を変更する場合は、旧形式を読み込めるようにして既存の進行状況を保つ。
- 指示されていないデザインや機能を変更しない。
- 修正内容、実施したテストとその結果、未確認事項があればその範囲を簡潔に報告する。
